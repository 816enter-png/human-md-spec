## human.md — spec, patent, and protocol

Private companion to [human-md](https://github.com/816enter-png/human-md) (the app).

- `patent/` — claims, specification, figures, filing checklist
- `protocol/` — HIF spec, BLE service profile, NFC NDEF schema, trust chain
- `design/` — system, file-schema, trust-chain, use-cases, and form-factor diagrams
- `prompts/` — build prompts used to generate the app

**Do not make this repo public without reviewing patent implications first** — public disclosure starts a 12-month clock in the US and is an immediate bar in most other jurisdictions.
