## human.md — spec, patent draft, and protocol

Open companion to [human-md](https://github.com/816enter-png/human-md) (the app).

**human.md is the format. Your file is your `me.md`.** One portable markdown file that tells every AI who you are — tone, boundaries, accessibility needs, context — carried with you across vendors, and (in the hardware spec) on a biometric-gated NFC/BLE module with a cryptographic trust chain.

- `patent/` — provisional draft: claims, specification, figures, filing checklist
- `protocol/` — file format spec, BLE service profile, NFC NDEF schema, trust chain
- `design/` — system, file-schema, trust-chain, use-cases, and form-factor diagrams
- `prompts/` — build prompts used to generate the app

Drafted March 2026 by Geoffery LaCorte / 816 Enterprises LLC. Published deliberately on 2026-08-25 as open prior art — the point is the standard existing, not the monopoly.
